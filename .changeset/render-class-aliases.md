[experimental] A rendered page that repeats an element names each repeated StyleX class list by one short class in its first paint, so a large table or list writes a much smaller file: a 10,000-row grid goes from 52 MB to 18 MB. The page looks the same, also where scripts are blocked; its script draws with StyleX's own classes, and `--reverse` gives the page back exactly.
